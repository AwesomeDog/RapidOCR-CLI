Standalone RapidOCR Server

Drop an image and run OCR instantly.

This page is bundled inside the RapidOCR binary. It sends a JSON request with a base64 image to /api/ocr and renders recognized text, confidence scores, and box coordinates. Choose, paste, or drop an image to start OCR automatically. The first request may take longer while models cached and initialized.
